Understanding Favicon in HTML

What is a Favicon?

A favicon (short for "Favorite Icon") is a small icon that appears in a browser tab next to the webpage title. It helps users identify a website quickly.

Where Favicon need?

  • Browser tabs
  • Mobile home screen shortcuts

How to Add a Favicon?

Add the following code inside the <head> section:

<link rel="icon" type="image/png" href="favicon.png">

Replace favicon.png with the name of your image file.

Advantages of Using a Favicon

  1. Improves website branding.
  2. Makes tabs easy to identify.
  3. Provides a professional appearance.
  4. Enhances user experience.
