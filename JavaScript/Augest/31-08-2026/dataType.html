DataType

A data type defines the type of data stored in a variable, such as text, numbers, true/false values, or objects.And in Datatype has two types Primitive Datatype and Non-Primitive Datatype.


  1. Primitive Datatype

    2. Primitive Data Types are the basic data types in JavaScript that store a single value directly in memory. They are immutable, meaning their values cannot be changed after creation.It has 7 primitive data types in JavaScript.

    • String
    • Number
    • Boolean
    • Undefined
    • Null
    • BigInt
    • Symbol

    Important Points

    • Primitive data types store values directly.
    • They are immutable (cannot be changed in place).
    • Compared by value, not by reference.
    • They occupy less memory than reference types.


  2. Non-Primitive (Reference) Data Types

    3. Non-Primitive Data Types are data types that can store multiple values or complex collections of data. They are also called Reference Data Types because they store a reference (memory address) to the actual data.

    • Object
    • Array
    • Function
    • Date
    • Map
    • Set

    Important Points

    • Non-Primitive Data Types are also called Reference Data Types.
    • They can store multiple values.
    • They are mutable (their contents can be changed).
    • Objects, Arrays, and Functions are the main non-primitive types.
