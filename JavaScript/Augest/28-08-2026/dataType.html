JavaScript Variables, Data Types

JavaScript Variables

A variable is a named storage location used to store data values in a JavaScript program. Variables can hold different types of data and their values can be changed during program execution.

let name = "Jose"; Name is Variable

let age = 20; Age is Variable

Here Name and Age are the variables that stores the value 'Jose' as a string and age stores integer 20 as a value.

JavaScript Primitive Datatype

A data type specifies the kind of value that a variable can store. JavaScript supports different data types such as String, Number, Boolean, Undefined, Null, BigInt, and Symbol.

let name = "John"; ----------- // String (Stores text values.)

let age = 20; ----------- // Number (Stores numeric values.)

let isStudent = true; ----------- // Boolean (Stores true or false.)

let address; ----------- //Undefined (Variable declared but not assigned a value.)

let result = null; ----------- //Null (Represents an intentional empty value.)

let salary = 50000n; ----------- //BigInt (Stores very large integers.)

let id = Symbol("empId"); ----------- //Symbol (Stores unique identifiers.)
