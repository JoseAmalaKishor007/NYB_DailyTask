Scope Concept of Variables

1. Global Scope

A variable declared outside any function or block is said to have global scope. It can be accessed from anywhere in the program.

let greet = "Jose";
function showName() {
console.log(greet);
}
showName();
console.log(greet);

2. Function Scope

A variable declared inside a function using var has function scope. It can only be accessed within that function.

function fun() {
let age = 20;
console.log(age);
}
fun();
// console.log(age); // Error

3. Block Scope

A variable declared inside a block ({ }) using let or const has block scope. It can only be accessed within that block.

if (true) {
let city = "Dindigul";
console.log(city);
}
// console.log(city); // Error
