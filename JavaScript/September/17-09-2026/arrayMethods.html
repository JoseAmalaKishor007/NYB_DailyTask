Array Methods

Array methods are built-in functions provided by JavaScript arrays.

They help perform operations such as adding, removing, searching, sorting, transforming, and processing array elements.

1.Looping Through Arrays

Looping through arrays means accessing each element of an array one by one to perform an operation.

  1. Used to process each array element.
  2. for...of is simpler for arrays.
  3. Commonly used with arrays and collections.

2.some()

The some() method checks whether at least one element satisfies a condition.

  1. Commonly used with arrays and collections.
  2. Returns true if any element matches.

3. every()

The every() method checks whether all elements satisfy a condition.

  1. Stops checking after finding the first match.
  2. Returns false when one element fails.

4. join()

The join() method combines all array elements into a single string.

  1. Returns a string.
  2. Can use any separator.

5. sort()

The sort() method arranges array elements in ascending order by default.

  1. Modifies the original array.
  2. Use compare function for numbers.

6. Array Flattening

Array flattening converts nested arrays into a single array.

  1. Removes nesting levels.
  2. Infinity flattens all levels.

7. Removing Duplicates

Removing duplicates means keeping only unique values in an array.

  1. Set stores unique values only.
  2. Spread operator converts Set back to array.

8. map()

The map() method creates a new array by applying a function to every element.

  1. Returns a new array.
  2. Does not change the original array.

9. filter()

The filter() method creates a new array containing elements that satisfy a condition.

  1. Returns a new array.
  2. Keeps only matching elements.

10. reduce()

The reduce() method reduces all array elements to a single value.

  1. Returns a single value.
  2. Commonly used for sums, averages, and calculations.

11. forEach()

The forEach() method executes a function once for each array element.

  1. Does not return a new array.
  2. Used for displaying or processing elements.
  3. Cannot be stopped using break or continue.
