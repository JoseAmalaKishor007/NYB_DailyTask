Function

A function is a reusable block of code designed to perform a specific task. Functions help reduce code repetition and make programs easier to maintain.

  1. Function Decleration
  2. Function Expression
  1. Function Decleration

    2. A function declaration is the most common way to create a function.

    • Has a function name.
    • Can be called before its declaration (Hoisting).
    • Easy to read and maintain.

    function add(a, b) {
    return a + b;
    }
    console.log(add(10, 20));


  2. Function Expression

    3. A function can be stored inside a variable.

    • Function is treated as a value.
    • Can be assigned to variables.
    • Cannot be called before initialization.

    let multiply = function(a, b) {
    return a * b;
    };
    console.log(multiply(5, 4));


    • Named Function Expression

      • The function has its own name inside the expression.

      • Debugging.
      • Recursion.
      • Better error messages.

      let greet = function welcome() {
      console.log("Welcome");
      };
      greet();


    • Anonymous Function Expression

      • A function without a name.

      • No function name.
      • Mostly used as callbacks.
      • Short and simple.

      let greet = function() {
      console.log("Hello");
      };
      greet();


    • Arrow Functions (ES6)

      • Arrow functions provide a shorter syntax for writing functions.

      • Uses the => operator.
      • Shorter and cleaner syntax.
      • Often used for callbacks and array methods.

      const greet = () => {
      console.log("Hello");
      };
      greet();
