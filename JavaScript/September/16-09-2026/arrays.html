Arrays

An Array is a special JavaScript object used to store multiple values in a single variable.

Each value in an array is called an element and is stored with an index starting from 0.

  • Stores multiple values in one variable.
  • Index starts from 0.
  • Can store different data types.
  • Arrays are dynamic (size can change).

Multidimensional Arrays

A multidimensional array is an array that contains one or more arrays as its elements.

It is used to store data in a table-like structure with rows and columns.

  • Used to represent tables and matrices.
  • Access elements using multiple indexes.
  • First index = row, second index = column.

Adding Elements to an Array

Adding elements to an array means inserting new values into an existing array.

JavaScript provides methods like push(), unshift(), and splice() to add elements at different positions in an array.

  1. push() – Adds element(s) to the end of the array.
  2. unshift() – Adds element(s) to the beginning of the array.
  3. splice() – Adds element(s) at a specified position in the array.

Removing Elements to an Array

Removing elements from an array means deleting one or more values from an existing array.

JavaScript provides methods like pop(), shift(), and splice() to remove elements from different positions in an array.

  1. pop() – Removes the last element from the array.
  2. shift() – Removes the first element from the array.
  3. splice() – Removes element(s) from a specified position in the array.

Accessing Array Elements

Accessing array elements means retrieving or reading values stored in an array.

Array elements are accessed using their index number, which starts from 0.

  • First element index = 0
  • Second element index = 1
  • Last element index = length - 1

Array length

The length property returns the total number of elements present in an array.

It helps determine the size of an array and is commonly used in loops.

  • length is a property, not a method.
  • Array indexing starts from 0, but length starts counting from 1.
  • The value of length changes automatically when elements are added or removed.

includes()

The includes() method checks whether a specified element exists in an array.

It returns true if the element is found and false if it is not found.

  • It is case-sensitive.
  • Returns a Boolean value (true or false).
  • Useful for checking the presence of an element before performing operations.

indexOf()

The indexOf() method returns the index (position) of the first occurrence of a specified element in an array. If the element is not found, it returns -1.

  • Array indexing starts from 0.
  • Returns the first matching index only.
  • Returns -1 if the element does not exist.
  • It is case-sensitive.

lastIndexOf()

The lastIndexOf() method returns the index (position) of the last occurrence of a specified element in an array.

If the element is not found, it returns -1.

  • Returns the index of the last matching element.
  • Returns -1 if the element does not exist.

Making an Array Empty

Making an array empty means removing all elements from the array.

This is useful when you want to clear existing data and reuse the same array.

Methods of Making an Array Empty

  1. Assign Empty Array
  2. Using Length
  • length = 0 is the simplest and fastest way.
  • splice() removes all elements from the original array.
  • After clearing, the array still exists but contains no elements.

Combining Arrays

Combining arrays means merging two or more arrays into a single array.

JavaScript provides methods like concat() and the spread operator (...) to combine arrays.

Methods of Combining Arrays
