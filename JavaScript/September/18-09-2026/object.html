Sorting Without Built-in Methods

Sorting without built-in methods means arranging array elements in ascending or descending order without using JavaScript's sort() method. This is done by manually comparing and swapping elements using loops.

  • Does not use the sort() method.
  • Uses loops and comparison operators.
  • Helps understand sorting algorithms.

Objects

An object is a non-primitive data type used to store multiple related values as key-value pairs.

Objects help organize and manage data in a structured way.

  1. Objects store data in properties (key-value pairs).
  2. Keys are called properties, and values can be any data type.
  3. Objects are enclosed within curly braces {}.
  4. Objects are reference data types.

Creating Objects

Creating an object means defining and storing related data as key-value pairs inside an object.

JavaScript provides multiple ways to create objects.

1. Object Literal Method

Objects are created directly using curly braces {}.

  • Simplest and most commonly used method.
  • Easy to read and write.
  • Suitable for creating a single object.

2. Using new Object() Constructor

Objects are created using the built-in Object constructor

  • Uses the new keyword.
  • Properties are added after object creation.
  • Less commonly used than object literals.

3. Constructor Function Method

A function is used as a blueprint to create multiple objects.

  • Used to create many objects with the same structure.
  • this refers to the current object being created.
  • Requires the new keyword.

Object Properties and Methods

Object Properties:

Properties are the variables inside an object that store data as key-value pairs.

  • Properties store data.
  • Accessed using dot notation (object.property) or bracket notation (object["property"]).
  • Property values can be any data type.

Object Methods:

Methods are functions stored inside an object that perform actions on the object's data.

  • Methods are functions inside objects.
  • Used to perform actions.
  • this refers to the current object.

Copying Objects

Copying Objects means creating a new object from an existing object.

It is used when you want to duplicate an object without changing the original data.

Types of Object Copying

  • Normal Copy
  • Shallow Copy
  • Deep Copy

Normal Copy

In a normal copy, both variables refer to the same object in memory.

Changing one object will also affect the other.

  • No new object is created.
  • Both variables share the same memory location.
  • Changes in one object affect the other.

Shallow Copy

A shallow copy creates a new object, but nested objects are still copied by reference.

  • Creates a new top-level object.
  • Primitive values are copied independently.
  • Nested objects are still shared.

Deep Copy

A deep copy creates a completely independent copy, including all nested objects.

  • Creates a fully separate object.
  • Nested objects are copied independently.
  • Changes do not affect the original object.
