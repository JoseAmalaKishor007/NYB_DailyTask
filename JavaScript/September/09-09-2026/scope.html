Scope

Scope is the area where a variable can be accessed or used in a program.

It determines the visibility and lifetime of variables within different parts of the code.


Three Types of Scope :

  1. Global Scope
  2. Function Scope
  3. Block Scope

1.Global Scope

A variable declared outside all functions and blocks is in the global scope.

It can be accessed from anywhere in the program.

2. Function Scope

A variable declared inside a function can only be used within that function.

1.Block Scope

Variables declared using let and const inside {} are accessible only within that block.

Rules in Scope

  • Variables can only be accessed within their defined scope.

  • Inner scopes can access variables from outer scopes.

  • Outer scopes cannot access variables declared inside inner scopes.

  • Variables with the same name in different scopes are treated separately.

Difference Between Scope Types

Feature Global Scope Function Scope Block Scope
Declared Where Outside all functions Inside a function Inside {} block
Accessible Everywhere Only inside function Only inside block
Lifetime Entire program Until function ends Until block ends
Keywords var, let, const var, let, const let, const

Recursive Functions

A recursive function is a function that calls itself to solve a problem.

It breaks a large problem into smaller subproblems until a stopping condition (base case) is reached.



Advantages of Recursive Functions :

  1. Simplifies complex problems.
  2. Useful for tree and graph traversal.
  3. Reduces code length for repetitive tasks.

Disadvantages of Recursive Functions :

  1. Uses more memory due to function calls.
  2. Can cause stack overflow if the base case is missing.
