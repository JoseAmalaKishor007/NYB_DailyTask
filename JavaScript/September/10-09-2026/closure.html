IIFE (Immediately Invoked Function Expression)

An IIFE is a function that is defined and executed immediately after it is created.

Important Points :

  1. Runs only once when defined.
  2. Creates its own scope.
  3. Prevents global variable pollution.
  4. Commonly used before ES6 modules.

Closure

A closure is a function that remembers and can access variables from its outer function even after the outer function has finished executing.

Important Points :

  1. Accesses outer function variables.
  2. Retains data between function calls.
  3. Used for data privacy and encapsulation.
  4. Used for data privacy and encapsulation.

First-Class Functions

In JavaScript, functions are first-class citizens, meaning they can be treated like any other value.

Important Points :

  1. Functions can be assigned to variables.
  2. Functions can be passed as arguments.
  3. Functions can be returned from functions.
  4. Foundation for callbacks and closures.

Pure Functions

A pure function always returns the same output for the same input and does not modify any external data.

Important Points :

  1. Same input → Same output.
  2. No side effects.
  3. Does not change external variables.
  4. Easier to test and debug.

Impure Functions

An impure function does not always return the same output for the same input or modifies external data.

Important Points :

  1. Depends on external variables.
  2. May modify data outside the function.
  3. Can produce different results for the same input.
  4. Harder to test and debug.

Difference Between Pure and Impure Functions

Pure Function Impure Function
Same input gives same output Same input may give different output
