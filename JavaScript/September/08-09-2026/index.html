Recursive

Recursion is a programming technique in which a function solves a problem by calling itself with a smaller or simpler input until a stopping condition is reached.
A recursive solution breaks a large problem into smaller instances of the same problem.

Important Points :

  1. A base case is the condition that stops the function from calling itself.

  2. The recursive case is where the function calls itself with a smaller or simpler input.

  3. Every recursive function call is stored in the JavaScript call stack.

  4. Recursion works best when a problem can be broken down into smaller versions of itself.

  5. Many iterative solutions can also be written recursively.

var, let, and const

var is function-scoped and allows redeclaration, let is block-scoped and allows reassignment, while const is block-scoped and cannot be reassigned after declaration.

Feature var let const
Scope Function-scoped Block-scoped Block-scoped
Reassignment ✅ Allowed ✅Allowed ❌Not allowed
Redeclaration ✅ Allowed ❌ Not allowed in same scope ❌ Not allowed in same scope
Hoisted ✅ Yes ✅ Yes (Temporal Dead Zone) ✅ Yes (Temporal Dead Zone)
Must Initialize ❌ No ❌ No ✅ Yes
Preferred Usage Rarely used When value changes When value should not be reassigned

Hoisting

Hoisting is JavaScript's behavior of moving declarations to the top of their scope before the code is executed.

This means you can sometimes use variables or functions before they are declared in the code.
